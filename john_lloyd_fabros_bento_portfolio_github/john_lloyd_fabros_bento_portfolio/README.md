# John Lloyd Fabros — Executive Operations Portfolio

## Publish with GitHub Pages
1. Replace the existing repository `index.html` with this `index.html`.
2. Commit the file to the `main` branch.
3. Keep `admin-editor.html` private; do not upload it to the public repository.

## Bento layout update
The content sections now use an editorial bento grid: featured proof and case-study panels receive more space, while supporting cards are smaller and grouped by topic. The layout collapses responsively for tablets and phones. The approved hero section is not included in the bento CSS patch and remains unchanged.

## Local Admin Studio
Open `admin-editor.html` in Chrome, load the current `index.html`, edit text/links/images, then export an updated HTML file. Upload the exported file to GitHub to publish changes. The editor is a local owner tool, not a server-authenticated online account system.
